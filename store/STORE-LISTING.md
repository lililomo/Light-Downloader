# Store listing copy

Paste these into the Chrome Web Store and Firefox AMO dashboards.

## Name
Light Downloader Integration

## Summary (used as manifest `description`, ≤132 chars)
Capture browser downloads and send them to the Light Downloader desktop app for faster, multi-connection downloading.

## Category
- Chrome Web Store: **Productivity**
- Firefox AMO: **Download Management**

## Single purpose (Chrome requires one clear purpose)
This extension has one purpose: hand downloads you start in the browser to the
Light Downloader desktop app so it can download them with multiple connections.

## Detailed description
Light Downloader Integration connects your browser to the Light Downloader
desktop app (Windows).

When the desktop app is running, any download you start in the browser is handed
off to it automatically, so it can be downloaded faster using multiple parallel
connections, with pause/resume, a queue, and a speed limiter.

Features:
• Automatic capture of browser downloads (toggle on/off from the popup)
• Right-click a link, image, audio or video → "Download with Light Downloader"
• Right-click a page → "Download video from this page" (grabbed with yt-dlp)
• Passes the site's cookies, referrer and user-agent so downloads that need your
  login session work correctly

The extension talks ONLY to the Light Downloader app on your own computer
(http://127.0.0.1). It does not send anything to any remote server. If the
desktop app is not running, the browser downloads normally.

Requires the free Light Downloader desktop app.
